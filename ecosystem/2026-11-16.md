### T01 — Mojo compilation targets and cross-compilation (official documentation)

- **Lane:** technical reading/backlog, **publication/revision date unknown**; inspected 2026-11-16.
- **Canonical source:** https://mojolang.org/docs/tools/compilation/
- **Technical substance:** `mojo build --target-triple aarch64-unknown-linux-gnu --target-cpu cortex-a72 --emit object` supports generating target objects without requiring native target execution; `--emit asm` also exposes architecture-specific codegen. The documentation explicitly warns that producing a fully linked cross-compiled executable needs a target linker. GPU assembly emission uses different formats for NVIDIA, AMD and Metal.
- **Why this reading is useful:** separates an **arm64 code-generation inspection** from the unresolved **arm64 runtime CPU-clock** hypothesis. The former may be performed with a cross compiler; the latter still needs a real arm64 runtime and repeatable clocks. This is a methodological reading, not a claimed new compiler feature.
- **Evidence/maturity:** official documentation inspected; no target compiler was installed or invoked in this run, and target support is evolving. Cross-compiled assembly alone cannot establish performance.
- **Research angle:** emit matching scanner assembly for x86_64 and aarch64 with the same pinned Mojo version, inspect bounds checks and loop branches, then measure on native arm64 separately.
