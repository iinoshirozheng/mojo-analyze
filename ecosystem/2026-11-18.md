## Recent technical developments

### R01 — mojo-baro: GPU kernel, serving and measurement protocol (substantive new technical delta)
- **Canonical repository/owner:** https://github.com/amarbarosys/mojo-baro — amarbarosys; **domain:** GPU kernels, inference, performance methodology. **Lane:** recent technical update, original author's [November 16 update](https://forum.modular.com/t/a-mojo-fp16-gemm-that-beats-hipblaslt-on-a-consumer-rdna3-card-rx-7900-xtx-with-the-receipts/3471/6); observed November 18.
- **New/technical:** reported Gemma-family dense-engine integration, windowed/full attention kernel, 27B decode GEMV decomposition and verified-vs-rejected speculative decode variants. Original author explicitly reports a 3-row GEMV change from 88.8 to 65.9 microseconds and engine throughput 70.4 to 86.0 tok/s, with separate correctness/evaluation gates. The original thread also retracts earlier noisy 4096-cubed GEMM speedup and records slower Mojo-1.2 K-quant megakernel behavior. This is an unusually useful example of **keeping negative results and toolchain-specific regressions visible**.
- **Evidence:** repository README and original-author forum update inspected; toolchain pinned to MAX 26.7/Mojo 1.2.0; optimized deployment depends on Linux, ROCm and gfx1100. Claims are author measurements on limited hardware; no local GPU replay, assembly inspection or independent replication. **Research angle:** pre-register a same-input GPU-kernel timing protocol with warm clocks, an independent FP reference and a falsification threshold, separating kernel and full-engine gains.

- **Original:** https://forum.modular.com/t/a-mojo-fp16-gemm-that-beats-hipblaslt-on-a-consumer-rdna3-card-rx-7900-xtx-with-the-receipts/3471 — amarbaro, original September 6, 2026; updated November 16, 2026. **Lane:** technical reading/backlog, with recent substantive updates.
