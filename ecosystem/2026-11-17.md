## Recent developments and repository discoveries

### R01 — mojo-gemm — HPC/numerical kernels (new discovery)
- **Source/owner:** https://github.com/michael-lehn/mojo-gemm — Michael Lehn. **Lane:** new discovery; [original forum post, 2026-11-13](https://forum.modular.com/t/dgemm-in-mojo-with-neon-and-sme2-micro-kernels/3670); observed 2026-11-17.
- **Technical value:** block packing plus macro/microkernels, NEON 8×6 and SME2 32×16 double-precision tiles, arbitrary strides and storage-order-aware transpose path; README also documents Cholesky and MLIR-based linear algebra mapping.
- **Evidence/maturity:** README and original-author write-up inspected; author reports large GEMM near ulmBLAS on Apple M5 using Mojo 1.2.0, but this is not an independently reproduced result. SME2 inline assembly and platform constraints limit portability. The original comparison references [ulmBLAS commit 4a0b610e](https://github.com/michael-lehn/ulmBLAS/commit/4a0b610e).
- **Research:** compare packed-panel correctness against NumPy/BLAS for noncontiguous strides; separate packing, kernel, and small-matrix overhead.

### R02 — wavewait — GPU instruction-level profiling (new discovery)
- **Source/owner:** https://github.com/amarbarosys/wavewait — amarbarosys. **Lane:** new discovery; [author's 2026-11-14 tools showcase](https://forum.modular.com/t/tools-i-built-in-mojo/3673); observed 2026-11-17.
- **Technical value:** reads gfx1100 SQTT thread traces from rocprofv3 ATT, aligns trace packets to instructions, attributes stall cycles and diffs kernel captures; can inspect Mojo, HIP or hand-written assembly.
- **Evidence/maturity:** README and capture instructions inspected, with documented golden fixtures and explicit mismatched-walk failure. Requires RDNA3/ROCm and careful capture settings; profiling evidence is not a portable performance claim.
- **Research:** on compatible GPU, compare two equivalent kernels, verify cycle conservation and whether reported stall changes correspond to independently measured latency.

### R03 — mokei — developer tooling (new discovery)
- **Source/owner:** https://github.com/amarbarosys/mokei — amarbarosys. **Lane:** new discovery; [author's 2026-11-14 showcase](https://forum.modular.com/t/tools-i-built-in-mojo/3673); observed 2026-11-17.
- **Technical value:** Mojo line counter with 40-language TOML table, diff budgets, token estimates, duplicate blocks and untested-name hints.
- **Evidence/maturity:** README inspected; reports parity against tokei 15.0.0 on four corpora as of 2026-11-07, with known exceptions. Linux-only file-location approach; semantic counts are heuristics, not parser or coverage measurements.
- **Research:** replay documented fixtures against tokei and validate CRLF, Unicode, mixed-language and binary-file boundaries; do not treat name matching as test coverage.
