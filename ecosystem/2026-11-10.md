## Repository profiles (new discoveries, not necessarily newly created)
### R01 — [bpr/MojoDEC](https://github.com/bpr/MojoDEC) — discrete geometry / scientific PDE
**Owner bpr; new discovery, announced November 8.** README blob `68559def5064bf85e88fff110c95d1241e998a6e`. Implements simplicial/cubical complexes, exterior derivatives, Hodge stars, typed cochains, curvature and sparse solvers. Technical differentiator: exact algebraic chain identity `d∘d=0` and compile-time primal/dual degree constraints; provides mesh examples and oracle comparisons. **Limits:** README only, Mojo 1.3 nightly and vendored NuMojo; numerical accuracy and speed not independently checked. **Experiment:** construct tiny oriented meshes, verify boundary-of-boundary zero and compare Laplacian spectrum with independent rational/numerical oracle before measuring throughput.

### R02 — [bpr/proptest](https://github.com/bpr/proptest) — test generation / methodology
**Owner bpr; new discovery, announced November 8.** README blob `0a90ea0bc869da47dd77b86e7c83b2f9d79ccdfe`. Hypothesis-inspired recorded-choice Conjecture engine, shrinking, state machines, constrained types and replay; distinctive because shrinking is strategy-independent. **Limits:** README-level verification; requires Mojo 1.3 nightly, not run here. **Experiment:** seeded property-test oracle and shrink reproducibility on checksum protocol and parser invariants.
