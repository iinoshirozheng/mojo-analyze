## Repository discoveries (newly discovered, not necessarily new repositories)

### Numerical/scientific/formal
2. [henlamp/axisweave-mojo](https://github.com/henlamp/axisweave-mojo) — named-axis rearrangement, contraction, reduction, borrowed index views. 0.1.0 package targets Mojo 1.1 macOS ARM64; README also describes Float32 GPU operations on MAX Core 26.6, Apple tested by author, NVIDIA cross-compiled only. Linux experimental. Study transpose materialization versus strided view reduction with exact layout oracle.
3. [caspbian/mojogp](https://github.com/caspbian/mojogp) — Python-first exact Gaussian processes, JIT Mojo GPU kernels, dense and matrix-free paths, without Torch dependency. Pre-1.0, NVIDIA only at README observation; mixed inputs/multioutput routes experimental. Study small SPD kernel matrix against NumPy and separate JIT from solve runtime.
4. [Spellbound-Mojo/cvc5_mojo](https://github.com/Spellbound-Mojo/cvc5_mojo) — generated cvc5 SMT bindings with Python-like API, not a native solver. [v1.4.1.1 release](https://github.com/Spellbound-Mojo/cvc5_mojo/releases/tag/v1.4.1.1) targets Mojo 1.2 and APN Mojo 1.0.2. README says publication pending, official package list indicates 1.2; exact binary availability/platform not checked. Study satisfiable/unsatisfiable fixtures and separate FFI construction from solving.

### Graphics and desktop
5. [henlamp/usd-mojo](https://github.com/henlamp/usd-mojo) — typed OpenUSD scene snapshots via official C++ SDK, no Python calls in Mojo API; v0.2.0 adds Linux x86-64, layer/edit APIs and optional rendering, Mojo 1.2. [Release](https://github.com/henlamp/usd-mojo/releases/tag/v0.2.0), [community PR](https://github.com/modular/modular-community/pull/449); date/merge status not independently verified. Stage ownership and concurrency limitations; not a pure Mojo scene engine. Study typed mesh and transform roundtrip, distinguish SDK cost from wrapper.
6. [Phelsong/mojo-wayland](https://github.com/Phelsong/mojo-wayland) — generates client and xdg-shell protocol bindings from XML; hand-written runtime and small C event dispatcher, documented headless smoke and FFI probe. Catalog targets 1.2. Study generated opcode/ABI parity against wayland-scanner output; compositor integration not checked.
7. [Maelkiz/mojo-window](https://github.com/Maelkiz/mojo-window) — SDL3 dynamically loaded via FFI, typed input events and either RGBA8 pixel buffer or OpenGL context. Catalog targets 1.1; not an SDL replacement or GL binding. Study frame/event translation correctness and presentation overhead separately.
8. [Ryul0rd/vulkan-mojo](https://github.com/Ryul0rd/vulkan-mojo) — generated vk.xml bindings and staged global/instance/device function loaders. README explicitly unsafe, pointer origins not retained in structs, Linux only; catalog MAX 25.6. Study ABI struct sizes and pointer lifetime checks with validation layers before GPU measurement.

### Systems/storage/parsing
9. [henlamp/filelock-mojo](https://github.com/henlamp/filelock-mojo) — move-only Unix lock owners, borrowing guards, bounded reads and atomic UTF-8 publication. README requires stable lock inode and local trusted FS; atomic publication is not power-loss durability. 0.1.0 Mojo 1.1 macOS ARM64, Linux experimental. Study concurrent reader/writer complete snapshots with controlled failures, distinguish visibility from crash durability.
10. [idlab-discover/mojo-snappy](https://github.com/idlab-discover/mojo-snappy) — raw Snappy block compression, bounded decode, caller-owned output and byte Span inputs; 0.2.1 pinned Mojo 1.2, optional Python/PyArrow/cramjam dev oracles. Framed format and CRC32C explicitly unsupported. Study malformed offsets, output bounds and compress-into vs allocation; verify with independent decoder.
11. [Hammad-hab/MojoINI](https://github.com/Hammad-hab/MojoINI) — simple INI sections/keys/comment parsing; author compares 100k keys with Python configparser, no independent timing; catalog MAX 25.4 is old. Study explicitly matched duplicate keys, interpolation and case semantics before comparing throughput.

### Developer tooling/interoperability
12. [MoSafi2/mojo_libclang](https://github.com/MoSafi2/mojo_libclang) — libclang bindings with cursor traversal, in-memory buffers and diagnostics. Stable v0.2.0 Mojo 1.2; nightly v0.3.0-dev.20261031 uses by-value structs/callbacks without native shim per README. [Stable tag](https://github.com/MoSafi2/mojo_libclang/tree/v0.2.0), [nightly tag](https://github.com/MoSafi2/mojo_libclang/tree/v0.3.0-dev.20261031). This wraps LLVM, not a new parser. Study C layout/return-by-value and callback ABI across architectures.
13. [mikeleppane/mtest](https://github.com/mikeleppane/mtest) — per-file stdlib TestSuite orchestration, builds/runs supervised binaries and aggregates reports for CI; README documents linux-64 and osx-arm64 packages, toolchain version must match release. Study fixture matrix for compile failures, timeouts, failing assertions and exit status, separate build from test execution.
