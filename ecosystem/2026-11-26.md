### Systems, storage and web

1. **[Mojara](https://github.com/mojara-framework/mojara)** (recent original [Nov 25 showcase](https://forum.modular.com/t/introducing-mojara-a-native-web-framework-for-mojo/3708); README). A full application framework including middleware, templates, database pooling, migrations/CLI, auth and WebSockets. [Nov 11 commit](https://github.com/mojara-framework/mojara/commit/052454e291c966c29c091098e846817bfb39eb62) concerns macOS installer package. README distinguishes x86-64 1.2.10 distribution from ARM64 1.2.9 and containerized macOS; don't equate these release/platform paths. Candidate: fixed route plus database workload, compare raw HTTP and full middleware separately; correctness before load.
2. **[Mojolt](https://github.com/ersh04/mojolt)** (recent Nov 24 [showcase](https://forum.modular.com/t/websocket-library-for-mojo-1-2/3707), [README commit](https://github.com/ersh04/mojolt/commit/4dc37b3364445bc6273ba842f9a1fca789974f8a)). Mojo 1.2 Linux epoll server and synchronous client, C socket shim, independent fragmentation/reassembly tests. Early stage; no native TLS/compression, callbacks run on one event-loop thread. Derived code attribution retained. Candidate: fragmented frame oracle and latency under deliberately slow handler, not an apples-to-apples raw HTTP throughput claim.
3. **[amarbaro/mojo-libs](https://github.com/amarbaro/mojo-libs)** (recent consolidation and release engineering deep dive; [Nov 26 commit](https://github.com/amarbaro/mojo-libs/commit/5b41eef273481e77994fab5182db5f717c959fbd)). README and [CV](https://github.com/amarbaro/mojo-libs/tree/main/libs/cv), [SQLite](https://github.com/amarbaro/mojo-libs/tree/main/libs/sqlite), [bench](https://github.com/amarbaro/mojo-libs/tree/main/libs/bench) READMEs inspected. One monorepo, individual package versions, sibling dependencies, external oracles and weekly nightly matrix. Old standalone CV/SQLite READMEs explicitly redirect here; count once. CV is CPU-native, MAX 26.7, not a GPU/OpenCV replacement; SQLite uses system libsqlite3 and borrowed views, not a rewritten database. Benchmark harness documents robust statistics. Author's SQLite comparison uses only three runs, not reproduced. Recent commit corrects release-note range handling after cherry-pick. Candidate: separate SQLite engine time from row materialization, or CV border-mode oracle.
4. **[avro.mojo](https://github.com/magmalake/avro.mojo)** (recent [v0.5.1 merge, Nov 25 UTC](https://github.com/magmalake/avro.mojo/commit/944f3c54a5d7782dff15115b7cee581d64af23c3)). README and pixi manifest inspected: schema parsing, OCF, projection via reusable RecordCursor and schema-plan caching. Core native; optional codecs depend on sibling packages, and manifest shows deflate dependency even for core build tasks. Pinned 1.3.0.dev2026112505. Author's roughly 11x cursor comparison is not reproduced and compares different materialization strategies. Candidate: same projected fields and exact output, separate plan creation from record traversal.
5. **[threads.mojo](https://github.com/magmalake/threads.mojo)** (recent [0.7.1 merge, Nov 25 UTC](https://github.com/magmalake/threads.mojo/commit/c980985b05de444198de1e4552b08580e58bab12)). README describes direct pthread calls, atomics, mutex, parallel_for and persistent WorkerPool, with state passed through a live argument. Pinned same nightly, Linux x86-64 and Apple ARM64 documented CI, not Linux ARM64 evidence. Native OS threads are not a pure language scheduler. Candidate: exact sum oracle and worker creation vs persistent pool overhead, inspect shared state safety.
6. **[mojo-dotenv](https://github.com/DataBooth/mojo-dotenv)** (discovery; [Aug 16 migration](https://github.com/DataBooth/mojo-dotenv/commit/3ed733605f25ed2e6f60d9adec5745beb1c163aa)). README documents expansion, quoting, multiline values, escape handling and environment loading; catalog pins 0.26.1 while README claims newer compatibility, so verify resolved package and compiler. Author's compatibility percentages aren't independently checked. Candidate: compare parsed maps and process environment effects separately, using fixtures rather than real secrets.
7. **[grpc-mojo](https://github.com/nsalerni/grpc-mojo)** (discovery; README, date not confirmed). Unary and three streaming RPC styles, deadlines/cancellation, generated stubs and CI compliance report. Catalog pins compiler >=1.0,<1.1; depends on sibling network/TLS/HTTP2/protobuf projects, not one standalone transport. Candidate: message parity and streaming backpressure with same serialization and transport settings.

### Numerical, UI and developer tools

8. **[Strata](https://github.com/ethqnol/strata-mojo)** (recent [Nov 20 probabilistic-models merge](https://github.com/ethqnol/strata-mojo/commit/6a340559eb164a2527aba48a061e7598820a7fda)). README describes sklearn-style models, sparse/dense matrices and SIMD, plus external LAPACK/BLAS for many linear algebra operations. Catalog pins 1.0; README says >=1.0.0. Author tables report speedups and parity metrics, but equal scores alone do not establish bitwise prediction equality. Candidate: compare arrays, same BLAS and thread counts, isolate fit and predict.
9. **[NuMojo](https://github.com/Mojo-Numerics-and-Algorithms-group/NuMojo)** (recent [Nov 25 PR #441 commit](https://github.com/Mojo-Numerics-and-Algorithms-group/NuMojo/commit/7e5e4605161e4cf74c811546ae7b6c1dc01b2462)). README retrieval failed; official catalog and actual implementation/test diff inspected instead. New routines include divmod, logaddexp/logaddexp2, frexp/ldexp, spacing, signbit. Diff adds NumPy comparison tests; float_power requires floating input rather than NumPy-style automatic promotion. Catalog 1.2 range. Candidate: signed zero, infinities, NaN and cancellation correctness before any SIMD measurement. No test execution.
10. **[mog](https://github.com/thatstoasty/mog)** (discovery; [Oct 27 README commit](https://github.com/thatstoasty/mog/commit/99970cfcac9c896398ed20f2079f0b8d0bb81fe5)). Mojo 1.2 terminal layout and color degradation, Lip Gloss-inspired style API. README notes chaining cost without controlled measurements; distinct from mist's styling primitives. Candidate: golden terminal output for fixed profiles and Unicode display widths, exclude terminal I/O from formatting benchmark.
11. **[mogo_tester](https://github.com/moseschmiedel/mogo_tester)** (recent [Nov 23 CI change](https://github.com/moseschmiedel/mogo_tester/commit/b0053e1d26df317d88a5b81cfbd644d45abb7772); README). Builds and runs separate test binaries with pseudo-TTY output, optional parallel jobs/precompile/ASAN. Runner uses 1.2 runtime but compiler for test targets is PATH-selected; x86-64 package needs AVX2. Candidate: test failure propagation, compiler provenance and terminal vs captured output; do not compare compile+run to execution-only.
12. **[UUID](https://github.com/lczerniawski/uuid)** (discovery; [Sep 1 recipe commit](https://github.com/lczerniawski/uuid/commit/97845805519e67682bbf7858bf5dfd378bb00e9d)). Candidate: RFC 9562 fixtures, invalid version/variant handling, deterministic v3/v5 versus Python; separate RNG from formatting.

## Original technical readings

- **T01 — [Refining function access sets](https://github.com/modular/modular/blob/main/Mojo/proposals/origin-access-refinement.md)**, Chris Lattner proposal dated Nov 15; [Nov 25 discussion](https://forum.modular.com/t/refining-function-access-sets-in-mojo/3712). Proposed field-level access contracts separate permitted dereferences from provenance, with checked disjoint access and transitive function-type contracts. Parametric ref read-only is an incremental implemented change; general accesses syntax is proposal, not shipped. Useful for future checked Span and interior-origin regression fixtures.
- **T02 — [Mojo C FFI manual](https://mojolang.org/docs/manual/c-ffi/)**, official undated technical reading. Direct native calls require exact ABI declarations and ownership discipline, particularly variadics and output pointers. A correct x86 run does not prove ARM64 ABI correctness; use C-header-derived types and compare struct layout against compiled C. Useful for clock_gettime probe. No performance claim adopted.
- **T03 — [Mojo time module](https://mojolang.org/docs/std/time/time/)**, official 1.0-era reference, undated. Performance counter includes sleep, so it cannot by itself attribute scheduled CPU work. Compare explicit region thread CPU clocks; check exact toolchain's implementations.
- **T04 — [SIMD API](https://mojolang.org/1.1.0/docs/std/simd/SIMD/)**, official versioned 1.1 reference, undated. Older shuffle mask uses IndexList; today's nightly announcement changes the type. Useful for constructing a fixed-permutation output oracle across SDK versions; no assertion of changed codegen.
