## Repository discoveries / distinct technical deep dives

### R01 — [grame-cncm/faust-rs](https://github.com/grame-cncm/faust-rs) — Faust→Mojo audio DSP code generation
**Lane: recent development, author report November 8. Owner: grame-cncm.** [Original technical announcement](https://forum.modular.com/t/faust-mojo-a-mojo-backend-in-faust-rs-and-running-thousands-of-audio-dsp-instances-on-the-gpu/3644). The experimental Rust compiler port emits Mojo DSP structs; author reports 132 impulse-response tests passing on Mojo 1.1/1.3 nightly and benchmarks 4,096 independent voices on Apple M5 Metal. Technical novelty is **structure-of-arrays state across many independent recursive processors**, not parallelization of one recursive reverb. Author reports a 20–31× layout effect on some large-state workloads, and GPU/CPU crossover depending on voice count; neither reproduced here. The author explicitly corrects an earlier unfair CPU baseline and reports latency/jitter limits and GPU f32 drift. README inspected (blob `92e86d6b02bae765dc29aa6bacd0d70c3631fa40`). **Experiment:** deterministic impulse oracle, then same-workload AoS/SoA comparison with identical CPU reference and GPU transfer costs; separate author-reported from verified results.
