## Recent developments
1. **Sep-25 Nightly:** Mojo `1.2.0.dev2026092505` / MAX `26.7.0.dev2026092505`. Source: https://github.com/modular/modular/commit/4685fc8aedbc4c333bca351401718e2bb38b23d2 . A version pin is a differential target, not evidence that older findings are fixed.
2. **Range lowering:** `for i in range(n)` is raised to structured `hlcf.for` with semantics preserved. Source: https://github.com/modular/modular/commit/42b67ce908bbf8f89c62f0c81b622d628bb3287c . This may change canonicalization/codegen and deserves an IR-first differential.
3. **Comptime control-flow IR:** `hlcf.comptime.if` gains `elif`, dedicated comptime-match IR is removed, and lifetime/canonicalization support is updated. Sources: https://github.com/modular/modular/commit/15693699e9d9c331b0dbf6709b720e9863d29fdf and https://github.com/modular/modular/commit/142f603cc2c72f0df50f15b1b55f6b21c5e222ca .
4. **Lamport allreduce correctness:** mixed fp32/bf16 calls could leave stale signal bytes because clear extent depended on the next dtype; extent is now recorded in 16-byte packs with regression coverage. Source: https://github.com/modular/modular/commit/8711000f409d830495bab3549105daa6cb8db67b .

## Repository discoveries
1. **shivasankarka/mojoBLAS** — pure-Mojo BLAS L1/L2/L3, tests and system-BLAS benchmarks; Mojo >=1.0,<2. Numerical oracle + codegen makes a better first replication than copying author timings. https://github.com/shivasankarka/mojoBLAS
2. **mmmaudio/mmmaudio** — Mojo realtime DSP with Python control, SIMD/parallel CPU processing and an ICMC 2026 paper. Headless signal graphs offer deterministic audio oracles. https://github.com/mmmaudio/mmmaudio
3. **kszucs/marrow** — Arrow layouts/kernels, Parquet/IPC, push query engine, Python C-Data interop and GPU paths. Current docs report 215/278 DuckDB-derived golden SQL queries passing; project remains experimental. Recent join cost-model change: https://github.com/kszucs/marrow/commit/ba98cae54c7e30bb5f185572290f4be05c03cd58
4. **thatstoasty/floki** — requests-like HTTP client over libcurl plus a small C shim for variadic calls. Useful FFI boundary case; end-to-end HTTP is not a language microbenchmark. https://github.com/thatstoasty/floki
5. **MoSafi2/BlazeSeq** — FASTA/FASTQ-style bioinformatics parsing with scan/SIMD structure and validation controls. Candidate: exact record digest before scalar/SIMD timing. https://github.com/MoSafi2/BlazeSeq
6. **unum-science/AffineGaps** — exact sequence alignment/folding families with CPU/GPU backends. Exact scores/tracebacks are strong oracles; transfer/setup must be separated. https://github.com/unum-science/AffineGaps
7. **Ameyanagi/nerai** — nonlinear least-squares/optimization with deterministic data, tests, profiling and benchmarks. Residual/final-parameter correctness should precede timing. https://github.com/Ameyanagi/nerai
8. **andomeder/mojo-intel-gpu** — Intel Level Zero FFI and external SPIR-V kernels, broadening accelerator coverage beyond CUDA/Metal. Real device execution is required before claims. https://github.com/andomeder/mojo-intel-gpu
9. **Hundo1018/wgpu-mojo** — wgpu-native bindings with callback/window bridges; recently pinned to Mojo 1.1. A headless buffer compute/readback oracle is cleaner than frame rate. https://github.com/Hundo1018/wgpu-mojo
10. **mojomath/stamojo** — statistics/special functions inspired by SciPy/statsmodels. Requires relative/ULP/domain-edge correctness, not checksum-only validation. https://github.com/mojomath/stamojo
11. **forfudan/argmojo** — mature CLI parsing/tooling surface with compile-time validation, subcommands, completions and CJK handling; v0.9 targets Mojo 1.1. https://github.com/forfudan/argmojo
12. **ehsanmok/flare** — HTTP/1.1/2/3, QUIC, WebSocket, TLS and one nonblocking reactor with fuzzing. README performance claims are author-reported; deterministic codecs/routing are better initial replication targets. https://github.com/ehsanmok/flare
13. **msaelices/mojo-regex** — hybrid DFA/NFA/PikeVM/LazyDFA plus experimental comptime DFA construction. Ideal for measuring where work moves: build time/binary size vs first-use and steady-state runtime. https://github.com/msaelices/mojo-regex
